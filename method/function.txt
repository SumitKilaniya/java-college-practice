METHODS IN JAVA------>in java methods are blocks of code that perform a specific task . a ,ethod allows us to reuse the code , improving effeciency and organisation . all methods in java must belomng to class 
advantages of methods-->
1. reusability--methods allow us to write code once and use it many times.
2. abstraction--methods allow us to abstract complex logic and provide a simple interface for others to use.
3. encapsulation--it allow to encapsulate complex logicand data.
4. modularity--methods allows us to break code into small more manageable units , imroving the modularity of code.
5. customisation--easy to customise a specific task.
6. improve performance--by organising the code into well structured ,methods , it can improve performance by reducing the ammount of code .
